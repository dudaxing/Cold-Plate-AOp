# Cold-Plate-AOp

Density-based topology optimization for thermal–fluid problems, on
[TOFLUX](https://github.com/UW-ERSL/TOFLUX)'s differentiable JAX core.

The project lives in **[`thermal-fluid-cold-plate/`](thermal-fluid-cold-plate/)** —
start with its [README](thermal-fluid-cold-plate/README.md).

Reproducing Zhao et al., *Applied Thermal Engineering* **291** (2026) 130088
with a per-element density parametrisation in place of the paper's CBS
features. The conformal-cooling work (Zhou et al.) has its own repository.
